Backup Meu Financeiro

O Backup Meu Financeiro é uma integração de uso pessoal destinada à criação e ao armazenamento de cópias de segurança do banco de dados do aplicativo privado Meu Financeiro.

Como funciona

O processo foi projetado para exportar os dados do banco, criptografar localmente os arquivos de backup no ambiente de execução e utilizar o Rclone, por meio da API do Google Drive, para enviar e conferir os arquivos na conta Google autorizada pela titular. A finalidade é permitir a recuperação dos dados em caso de falha ou perda.

Acesso e privacidade

Esta página é apenas informativa. Ela não oferece login, não contém dados financeiros e não disponibiliza acesso ao aplicativo, ao banco de dados ou às cópias de segurança. A integração destina-se exclusivamente à titular da conta que a autoriza.

Para conhecer o tratamento dos dados e as condições de uso, consulte a Política de privacidade e os Termos de uso.
